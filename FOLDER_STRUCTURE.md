# Project Folder Structure

## Overview

```
agentic-playwright-demo/
├── specs/                          # BDD specifications (source of truth)
│   └── saucedemo.spec.md          # 4 user journey scenarios
├── tests/                          # Generated Playwright tests
│   └── saucedemo.spec.ts          # Agent-generated test file (no page objects)
├── artifacts/                      # Generated output files (git-ignored)
│   ├── reports/                   # Test reports
│   │   └── playwright-report/     # HTML test execution report
│   ├── evidence/                  # Test execution evidence
│   │   └── test-results/          # Screenshots, traces, videos on failure
│   └── generated/                 # Other generated artifacts
├── .github/
│   └── skills/                    # Agent skills
│       ├── playwright-cli/        # Browser automation CLI
│       └── spec-driven-playwright/ # Agentic workflow documentation
├── playwright.config.ts           # Playwright configuration
├── package.json                   # Dependencies and scripts
├── plan.md                        # Implementation plan
└── README.md                      # Project documentation
```

## Directory Purposes

| Folder | Purpose | Git-tracked | Notes |
|--------|---------|-------------|-------|
| `specs/` | BDD specifications | ✅ Yes | Source of truth for tests |
| `tests/` | Playwright test files | ✅ Yes | Generated by agent, no page objects |
| `artifacts/reports/` | HTML test reports | ❌ No | Created by `npm test` |
| `artifacts/evidence/` | Screenshots, traces, videos | ❌ No | Playwright captures on failure |
| `artifacts/generated/` | Other generated files | ❌ No | Reserved for future output |
| `.github/skills/` | Agent skill documentation | ✅ Yes | Workflow and tool references |

## Key Principles

1. **Source vs. Generated**
   - `specs/` and `tests/` are source files (committed to git)
   - `artifacts/` contains generated output (git-ignored)

2. **No Page Objects**
   - Tests are generated fresh by the agent
   - Locators are discovered dynamically during exploration
   - No manual page-object maintenance needed

3. **Clean Artifacts**
   - All output files centralized in `artifacts/`
   - Keeps project root clean
   - Easy to share or clean up test evidence

## Running Tests

```bash
# Install dependencies
npm install && npx playwright install chromium

# Run tests (output goes to artifacts/)
npm test

# View HTML report
npx playwright show-report artifacts/reports/playwright-report
```

## Generated File Locations

After running `npm test`:

```
artifacts/
├── reports/
│   └── playwright-report/
│       ├── index.html             # Test summary and results
│       ├── test-*.html            # Individual test reports with traces
│       └── ...                     # Playwright report assets
└── evidence/
    └── test-results/
        ├── saucedemo.spec.ts-*-*.png     # Screenshots on failure
        ├── trace.zip                      # Full execution trace
        └── ...
```

## Ignored Files

The following are automatically excluded from git (see `.gitignore`):

- Screenshots and videos in `artifacts/evidence/`
- HTML reports in `artifacts/reports/`
- Node modules
- Playwright CLI session data
